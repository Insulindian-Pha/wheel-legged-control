# 关节角度处理差异说明

## 问题描述

`Simulation.py` 和 `mujoco_ros2_control.launch.py` 启动时关节反馈角度不一致。

## 两个系统的处理流程对比

### Simulation.py 的处理流程

1. **environment.py 中读取传感器并应用偏移**：
   ```python
   joint_pos[0] = sensor_jAB + 0.027  # 右前 (jAB)
   joint_pos[1] = sensor_jAG + 1.3     # 右后 (jAG)
   joint_pos[2] = sensor_jIJ + 0.003   # 左前 (jIJ)
   joint_pos[3] = sensor_jIO - 1.3     # 左后 (jIO)
   ```

2. **Simulation.py 中 VMC 计算**：
   ```python
   # 右腿
   vmc_r.vmc_calc_pos(
       phi1=joint_pos[0] + π = (sensor_jAB + 0.027) + π,
       phi4=joint_pos[1] = sensor_jAG + 1.3  # 注意：phi4没有加π
   )
   
   # 左腿
   vmc_l.vmc_calc_pos(
       phi1=joint_pos[3] + π = (sensor_jIO - 1.3) + π,
       phi4=joint_pos[2] = sensor_jIJ + 0.003  # 注意：phi4没有加π
   )
   ```

### vmc_controller.cpp 的处理流程

1. **从 ros2_control 获取原始值（无偏移）**：
   - `left_front_pos_raw` = sensor_jIJ
   - `left_rear_pos_raw` = sensor_jIO
   - `right_front_pos_raw` = sensor_jAB
   - `right_rear_pos_raw` = sensor_jAG

2. **应用偏移**（从配置文件读取）：
   ```cpp
   left_front_pos = left_front_pos_raw + left_front_joint_offset
   left_rear_pos = left_rear_pos_raw + left_rear_joint_offset
   right_front_pos = right_front_pos_raw + right_front_joint_offset
   right_rear_pos = right_rear_pos_raw + right_rear_joint_offset
   ```

3. **VMC 计算（注意：左右腿交换，且 phi4 也加了 π）**：
   ```cpp
   // 左腿使用右腿的关节
   left_leg_.setPhi1(M_PI + right_front_pos);  // = π + (sensor_jAB + offset)
   left_leg_.setPhi4(M_PI + right_rear_pos);   // = π + (sensor_jAG + offset) 注意：phi4也加了π
   
   // 右腿使用左腿的关节
   right_leg_.setPhi1(M_PI + left_front_pos);  // = π + (sensor_jIJ + offset)
   right_leg_.setPhi4(M_PI + left_rear_pos);   // = π + (sensor_jIO + offset) 注意：phi4也加了π
   ```

## 关键差异

### 1. 偏移值不一致

- **Simulation.py** 使用：`[0.027, 1.3, 0.003, -1.3]`
  - jAB: +0.027
  - jAG: +1.3
  - jIJ: +0.003
  - jIO: -1.3

- **控制器配置**（之前）：`[3.1416, 0.0, 3.1416, 0.0]`
- **控制器配置**（已修复）：`[0.003, -1.3, 0.027, 1.3]`
  - jIJ (left_front): +0.003
  - jIO (left_rear): -1.3
  - jAB (right_front): +0.027
  - jAG (right_rear): +1.3

### 2. phi4 处理方式不同

- **Simulation.py**：phi4 **不加** π
  - 右腿：`phi4 = sensor_jAG + 1.3`
  - 左腿：`phi4 = sensor_jIJ + 0.003`

- **控制器**：phi4 **也加** π
  - 左腿：`phi4 = π + (sensor_jAG + offset)`
  - 右腿：`phi4 = π + (sensor_jIO + offset)`

### 3. 左右腿映射不同

- **Simulation.py**：
  - 右腿使用：jAB (phi1), jAG (phi4)
  - 左腿使用：jIO (phi1), jIJ (phi4)

- **控制器**（左右腿交换）：
  - 左腿使用：jAB (phi1), jAG (phi4)
  - 右腿使用：jIJ (phi1), jIO (phi4)

## 最终计算结果对比

### Simulation.py 最终值：
- 右腿：`phi1 = (sensor_jAB + 0.027) + π`, `phi4 = sensor_jAG + 1.3`
- 左腿：`phi1 = (sensor_jIO - 1.3) + π`, `phi4 = sensor_jIJ + 0.003`

### 控制器最终值（使用修复后的偏移）：
- 左腿：`phi1 = π + (sensor_jAB + 0.027)`, `phi4 = π + (sensor_jAG + 1.3)`
- 右腿：`phi1 = π + (sensor_jIJ + 0.003)`, `phi4 = π + (sensor_jIO - 1.3)`

## 差异总结

1. **phi1 值**：两者一致（都加了 π 和相同的偏移）
2. **phi4 值**：**不一致** - 控制器中 phi4 多加了 π

## 解决方案

### 方案1：修改控制器代码（推荐）

修改 `vmc_controller.cpp`，使 phi4 不加 π：

```cpp
// 修改前
left_leg_.setPhi4(M_PI + right_rear_pos);
right_leg_.setPhi4(M_PI + left_rear_pos);

// 修改后
left_leg_.setPhi4(right_rear_pos);
right_leg_.setPhi4(left_rear_pos);
```

### 方案2：调整偏移值补偿

如果保持控制器代码不变，需要调整偏移值来补偿 phi4 多加的 π：

- jAG 偏移：`1.3 - π ≈ -1.8416`
- jIO 偏移：`-1.3 - π ≈ -4.4416`

但这会导致代码逻辑不一致，不推荐。

## 建议

**推荐使用方案1**，修改控制器代码使 phi4 不加 π，这样与 Simulation.py 的逻辑一致。
