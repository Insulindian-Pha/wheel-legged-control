# wheel_leg_mujoco 包中初始位置定位说明

## 概述

这个Python MuJoCo仿真包中，初始位置的定位通过**硬编码的偏移值**来实现，类似于C++控制器中的`joint_offset`机制。

## 初始位置定位方式

### 1. MuJoCo模型中的初始位置

在 `MJCF/robot.xml` 中：
- 关节（joint）**没有显式设置初始位置**（qpos），默认都是 **0 rad**
- 通过body的`pos`和`quat`属性定义物理结构的位置和姿态
- 关节定义：
  - `jAB` (右前关节): `range="-1.57 0.5"`
  - `jAG` (右后关节): `range="-1.57 0.3"`
  - `jIJ` (左前关节): `range="-0.5 1.57"`
  - `jIO` (左后关节): `range="-0.3 1.57"`

### 2. 代码中的偏移值（关键部分）

在 `environment.py` 的 `sensor_read_data()` 方法中（第71-77行），有**硬编码的偏移值**：

```python
# 右前关节位置
right_front_pos = self.data.sensor('Right_front_joint_pos').data.copy()[0] + 0.027  # AB
# 右后关节位置
right_rear_pos = self.data.sensor('Right_rear_joint_pos').data.copy()[0] + 1.3      # AG
# 左前关节位置
left_front_pos = self.data.sensor('Left_front_joint_pos').data.copy()[0] + 0.003     # IJ
# 左后关节位置
left_rear_pos = self.data.sensor('Left_rear_joint_pos').data.copy()[0] - 1.3       # IO
```

**偏移值总结：**
- 右前关节（jAB）: **+0.027 rad** ≈ 1.55°
- 右后关节（jAG）: **+1.3 rad** ≈ 74.5°
- 左前关节（jIJ）: **+0.003 rad** ≈ 0.17°
- 左后关节（jIO）: **-1.3 rad** ≈ -74.5°

### 3. VMC计算时的进一步处理

在 `Simulation.py` 中（第34-35行），VMC计算时还会加上 **π (180°)**：

```python
# 右腿
vmc_r.vmc_calc_pos(
    phi1=GBC486.joint_pos[0] + math.pi,  # 右前关节 + π
    phi4=GBC486.joint_pos[1],            # 右后关节
    pitch=GBC486.euler[1],
    gyro=GBC486.gyro[1]
)

# 左腿
vmc_l.vmc_calc_pos(
    phi1=GBC486.joint_pos[3] + math.pi,  # 左后关节 + π
    phi4=GBC486.joint_pos[2],            # 左前关节
    pitch=-GBC486.euler[1],
    gyro=-GBC486.gyro[1]
)
```

**注意：**
- 右腿使用 `joint_pos[0]` (右前) 和 `joint_pos[1]` (右后)
- 左腿使用 `joint_pos[3]` (左后) 和 `joint_pos[2]` (左前)
- 两个`phi1`都加上了`math.pi`

## 与C++控制器的对应关系

### Python版本（wheel_leg_mujoco）：
```python
# 1. 读取传感器 + 偏移
right_front_pos = sensor_value + 0.027
right_rear_pos = sensor_value + 1.3
left_front_pos = sensor_value + 0.003
left_rear_pos = sensor_value - 1.3

# 2. VMC计算时 + π
phi1 = joint_pos + math.pi
```

### C++版本（vmc_controller）：
```cpp
// 1. 读取状态 + 偏移
left_front_pos = left_front_pos_raw + left_front_joint_offset_;
left_rear_pos = left_rear_pos_raw + left_rear_joint_offset_;

// 2. VMC计算时 + π/2
left_leg_.setPhi1(M_PI / 2.0f + left_front_pos);
left_leg_.setPhi4(M_PI / 2.0f + left_rear_pos);
```

**差异：**
- Python版本加的是 **π (180°)**
- C++版本加的是 **π/2 (90°)**

## 如何确定这些偏移值

这些偏移值（0.027, 1.3, 0.003, -1.3）是通过以下方式确定的：

1. **物理测量**：将机器人放置在期望的初始位置（零点位置）
2. **读取关节角度**：从MuJoCo传感器读取原始角度值
3. **计算偏移**：使偏移后的角度符合VMC算法的坐标系要求
4. **硬编码**：直接写在代码中

## 修改初始位置的方法

如果需要修改初始位置：

1. **修改偏移值**：在 `environment.py` 的 `sensor_read_data()` 方法中修改偏移值
2. **或者修改模型**：在 `robot.xml` 中为关节添加初始位置（qpos），但这需要重新设计偏移值

## 注意事项

1. **偏移值的符号**：
   - 右后关节：`+1.3`（正偏移）
   - 左后关节：`-1.3`（负偏移，符号相反）

2. **单位**：所有角度值使用**弧度（rad）**

3. **坐标系转换**：偏移值不仅用于零点校准，还用于坐标系转换（从MuJoCo坐标系到VMC算法坐标系）

4. **与C++版本的对应**：
   - 如果要在C++控制器中实现相同的初始位置，需要：
     - 考虑Python版本中的偏移值（0.027, 1.3, 0.003, -1.3）
     - 考虑π和π/2的差异
     - 可能需要调整offset值
